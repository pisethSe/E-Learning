# Admin Frontend

Run the admin app from this folder:

```bash
npm install
npm run dev
```

Expected local URL:

- `http://127.0.0.1:5174`

Useful commands:

- `npm run dev` starts the admin development server on port `5174`
- `npm run build` creates the production build
- `npm run preview` previews the production build on port `4174`

This frontend is intended to work with:

- user frontend on `http://127.0.0.1:5173`
- backend API on `http://127.0.0.1:8000`
